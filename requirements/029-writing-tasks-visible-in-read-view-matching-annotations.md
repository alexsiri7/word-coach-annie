## Why

Authors create writing tasks from the Read view's selection popover ("Add task"), but nothing in Read view lets them see the resulting list afterward — they have to leave and go to the separate Tasks page on the project dashboard. Annotations already surface visibly in Read view (inline highlights, clickable to view), so by comparison tasks feel hidden and are easy to forget about.

## What

From the Read view, authors should be able to see and access the full list of writing tasks for the current project without leaving the page — with an entry point as easy to find as the existing annotations affordance. Each task in that list should show its name and completion status, and let the author act on it (e.g. mark complete) directly from Read view.
