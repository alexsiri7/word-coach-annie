## Why
The same structure works for novelists and article/non-fiction writers, but the UI labels should reflect the content type (Chapter vs. Article, Scene vs. Section).

## What
`FICTION`, `ARTICLE_COLLECTION`, and `GENERAL` project types with dynamic UI labels. Medium-optimized Markdown export for article projects.
